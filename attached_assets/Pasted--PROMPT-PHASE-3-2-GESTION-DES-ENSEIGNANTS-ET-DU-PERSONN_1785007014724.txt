# PARTIE C — OBJECTIF DE LA PHASE 3.2

Créer une gestion complète du personnel scolaire.

La structure principale sera :

```text
École
    ↓
Personnel
    ├── Enseignants
    ├── Personnel administratif
    └── Autres personnels
```

La Phase 3.2 doit principalement mettre en place :

* le personnel ;
* les enseignants ;
* les informations professionnelles ;
* les statuts ;
* les matricules du personnel ;
* les bases nécessaires aux futures affectations académiques.

# PARTIE D — ARCHITECTURE DU PERSONNEL

Un membre du personnel doit être lié à :

* une école ;

* un type de personnel ;
* un statut.


Les types exacts doivent respecter la documentation du projet.

Ne pas créer de rôles inutiles.
